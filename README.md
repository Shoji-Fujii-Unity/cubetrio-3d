# CUBETRIO 3D — キューブトリオ

積まれた **立体ブロック** を回転・ズームしながら観察し、同じ色（同じマーク）を **3つ** 揃えて消していく
横画面前提の **3Dブロックパズル** です。PC（マウス／キーボード）とスマートフォン（タッチ）の両方で遊べます。

| | |
|---|---|
| タイトル | **CUBETRIO 3D**（キューブトリオ） |
| ジャンル | 3Dマッチ3（三消し）ブロックパズル |
| 起動方法 | `index.html` をブラウザで開くだけ（ビルド不要・サーバー不要） |
| 3Dライブラリ | **three.js r0.161.0 を CDN（jsDelivr）から読み込み** |
| 対応言語 | 日本語 / English / 中文（画面内で切替・自動保存） |
| サウンド / BGM | WebAudio スタジオシンセ SE ＋ プロシージャル BGM（外部ファイルなし・個別 ON/OFF 保存） |
| セーブ | `localStorage`（`cubetrio3d.save.v1`）に ベストスコア・解放ステージ・言語・サウンド/BGM設定 |

## あそびかた

1. 積まれたブロックの山から **取れるブロック** をタップ／クリックすると、下の **トレイ（7マス）** に集まります。
2. 同じ色（同じマーク）が **3つ** 集まると消えてスコアになります。連続で消すと **コンボ倍率**（最大 x9）アップ。
3. **取れる条件** … 上に乗っているブロックが無い ＋ 横の4面のうち少なくとも1面が空き。
   （取れないブロックは色が暗く表示されます）
4. トレイが **7つ** 埋まるとゲームオーバー。山をすべて消したらステージクリア → 次のステージへ。
5. 詰まりそうなら **もどす（UNDO）** と **ならべかえ（SHUFFLE）** を使えます（各ステージ2回まで）。

**ステージは全12ステージ。** 最初のクリアで次のステージが解禁され、進行度は端末に保存されます。

## 画面

* **横長画面前提**のレイアウトです。縦向きで開くと「横画面にしてください」の案内が表示されます
  （`縦のまま続ける` で続行もできます）。スマホの横向き（例: 844×390）を基準に調整しています。
* 上段 left … レベル／スコア／ベスト／残りブロック数
* 上段 right … BGM ON-OFF・サウンドON-OFF・言語切替・あそびかた・やり直す・タイトル
* 下段 center … トレイ7マス（コンボタイマー・リーチ発光・満杯警告つき）と、もどす／ならべかえボタン
* タイトル画面の裏では、実際に生成されたステージが自動回転するアトラクトモードが動いています。

## 仕組み（わかりやすいポイント）

* **ステージ生成** … 段ごとの形状（満杯／リング＋中心／ひし形／穴あき四角）を組み合わせて山を作り、
  個数が **必ず3の倍数** になるよう表面のブロックから調整します。
  色は **3個1セットでランダム配置** するので、理論上すべてのステージがクリア可能です
  （同梱のがんくれーみBotで 12/12 ステージが完走できることを確認済み）。
* **描画** … 角丸立体ジオメトリ（`RoundedBoxGeometry`）＋ スタジオ環境反射（`RoomEnvironment`）＋ クリアコート物理マテリアル。
  色別グロス＆バンプマップテクスチャは Canvas で即時生成し、ネオン台座・3Dスパーク＆ショックウェーブ演出を備えています。
* **サウンド & BGM** … `AudioContext` によるコンボリューションリバーブ＆ステレオエコー搭載のシンセエンジン。
  8小節コード進行のプロシージャルBGM（タイトル時はアンビエント、プレイ中はベース＆パーカッションが加わる動的レイヤー）と立体的なSEをリアルタイム生成します。
* **セーブ** … スコア更新・ステージ進行・言語・音声設定を変えたときと、タブを隠れたときに書き込みます。

## 使い方

```
index.html をダブルクリック（またはブラウザにドラッグ）
```

* three.js を **CDNから取得するため初回はネット接続が必要** です。
  CDN取得または3D描画の初期化に失敗すると、画面に読み込みエラーが表示されます。
* ローカルサーバーを使う場合の例：

```powershell
# どちらでもOK
npx serve .
python -m http.server 8080
```

### コンソールから遊んでみる（開発用フック）

`index.html` は開発用の簡易フックを公開しています（通常のプレイでは触る必要はありません）。

```js
__CT.stats()        // 現在のレベル・残り・スコアなど
__CT.start(6)       // 6ステージ目を開始
__CT.pickSmart()    // 1手だけ賢く選ぶ
__CT.bot(true)      // 自動プレイ開始 / __CT.bot(false) で停止
__CT.langSet('zh')  // 言語切替
```

## 検証済み（ヘッドレスEdge / CDP）

* コンソールエラー・例外 **0件**（three.js CDN読み込み含む）
* STARTクリック → 48ブロックのステージ開始、HUD更新
* ピンチ操作でブロックを誤取得しないこと、消去処理中にUNDO / SHUFFLEが競合しないこと
* 実クリック（レイトキャスト）でトレイにブロックが乗ること
* ドラッグで視点回転、ピンチ/ホイール相当のズーム
* 3つ揃えで消去・スコア加算・コンボ表示
* UNDO / SHUFFLE の動作、ステージクリアと次ステージ解禁、ゲームオーバー表示
* 言語切替（ja/en/zh・`<html lang>` も追随）、サウンドON-OFF と保存
* 縦向きで「横画面にしてください」表示 → 横向きで自動解除
* **ページ再読み込み後のセーブ復元**と、不正なセーブ値を読み込んでも起動できること（localStorage）
* がんくれーみBotによる全12ステージ完走：**12 / 12 クリア**
